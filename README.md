# 그날의 남녀 (Heart-Sync)

커플의 생체 리듬 동기화와 활력 관리를 돕는 웰니스 웹 애플리케이션입니다. 회원가입 없이 브라우저에 데이터를 저장하는 방식으로 동작합니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 소개·유입 페이지 (30초 궁합 테스트) |
| `app.html` | 실제 프로그램 본체 |
| `ads.json` | 광고 데이터 백업 (평소에는 구글 시트가 우선 적용됨) |
| `vercel.json` | 캐시·URL 설정 |

## 광고 데이터 관리

광고 링크와 문구는 코드가 아니라 **구글 스프레드시트에서 관리**합니다. 시트를 수정하면 배포 없이 자동 반영되며, 보통 1~5분 내에 적용됩니다.

시트를 읽지 못하는 상황에서는 `ads.json`이 대신 사용되므로 이 파일을 삭제하지 마십시오.

## 수정 방법

GitHub에서 파일을 직접 편집하고 커밋하면 Vercel이 자동으로 새 버전을 배포합니다. 주소는 항상 동일하게 유지됩니다.

## 고지 사항

본 서비스는 의학적 진단이나 치료를 대체하지 않는 참고용 웰니스 서비스입니다. 앱 내 상품 링크는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
